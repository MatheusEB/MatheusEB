### Em destaque

**Gerador de Relatórios DGT** · app de Windows · uso interno, código privado

> **Problema:** os relatórios das ordens de serviço eram baixados um a um, pelo navegador.
> **Solução:** um app de desktop que entra no sistema em segundo plano e baixa os relatórios em lote, com
> interface própria, histórico e reprocessamento das falhas.
> **Resultado:** 2.000 OS viram 2.000 PDFs organizados numa pasta; desde a versão 2.20 o PDF é gerado no
> próprio computador e os lotes ficaram ~2x mais rápidos.

`Python` `Playwright` `WebView2` `JavaScript` · versão 2.21 · 270 testes automatizados
